---
description: Weekly review for the accounting practice
---

Run `npm run practice -- weekly-review $ARGUMENTS`.

Run attention, workload and wip separately, then write a Monday review with overdue decisions first, owners and next actions. Keep currencies separate. Do not invent commitments.

Use `--json` when analysing records. Base every answer on fresh output. If a name matches several records, list them and ask the operator to choose.
